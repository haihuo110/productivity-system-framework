## 1. Purpose
将已批准的 `WO-*` 实训工单适配为可重复、可暂停、可审计的虚拟实训包 `SIM-*`，并确保仿真行为与真实设备、教学目标和安全边界一致。

## 2. Inputs
- 已验证或明确处于审核中的 `WO-*`、`SCN-*`、`MOD-*`、`COMP-*`、`JOB-*`。
- VC 数字孪生资产、坐标系、材质、碰撞体、传感器和版本清单。
- 机器人型号、虚拟示教器 API、程序语言、速度/姿态/工具坐标约束。
- PLC I/O 点表、信号类型、极性、时序、仿真映射和真实设备校验记录。

## 3. Outputs
输出 `sim-package-v1.json`，包含资产映射、场景、虚拟示教器脚本、交互事件、checkpoint/resume 状态、PLC I/O 与示教坐标映射、验证证据和完整链：
`WO-* -> SIM-* -> AUDIT-*`，同时保留 `JOB-* -> COMP-* -> MOD-* -> SCN-* -> WO-*` 上游链。

## 4. Operating procedure
1. 锁定工单版本，建立 `SIM-*`，登记来源和适配器版本。
2. 将 VC 数字孪生组件映射到工位、机器人、工具、工件、传感器和碰撞体；记录比例、坐标系和精度。
3. 将机器人虚拟示教器动作编排为可回放脚本，明确关节/笛卡尔坐标、工具坐标、速度、姿态、等待和信号条件。
4. 建立交互层：抓取、放置、碰撞、限位、报警、确认和教师放行事件。
5. 为每个工单检查点生成可命名 checkpoint，保存程序、场景、I/O、坐标和学习者状态，支持从最近安全点恢复。
6. 映射 PLC I/O：地址、方向、数据类型、极性、默认态、触发时序、仿真信号和真实点表；对未确认点拒绝自动联机。
7. 映射示教坐标：基坐标、工具坐标、工件坐标、单位、容差和校准来源；禁止隐式单位转换。
8. 做行为等价、时序、碰撞、边界和恢复测试，记录偏差并提交安全审计。

## 5. Guardrails
仿真不是安全认证替代品；任何涉及真实执行器、PLC 或网络生产系统的连接必须由授权人员和 `AUDIT-*` 放行。默认使用隔离、限速、虚拟 I/O 和无动力模式。脚本不能绕过急停、门禁、联锁、限位或教师放行。

## 6. Verification
机器校验：schema、ID 链、资产版本、坐标单位、I/O 地址唯一、脚本可解析、checkpoint 可恢复、碰撞和异常路径覆盖。教师/工程师校验：目标等价、示教器可理解性、硬件映射和时序一致性。差异必须进入 `open_issues`，不得静默修正。

## 7. Failure handling
资产缺失时输出 `asset_gap`；I/O 或坐标不确定时输出 `mapping_blocker` 并锁定真实连接；恢复失败时保留故障快照、回退到上一个安全 checkpoint，并生成待审计事件。

## 8. ID tracking chain
`JOB-* -> COMP-* -> MOD-* -> SCN-* -> WO-* -> SIM-* -> AUDIT-*`。任何仿真包只允许绑定一个主 `WO-*`；派生版本使用新 `SIM-*` 和 `derived_from`，不得复用历史仿真包 ID。
